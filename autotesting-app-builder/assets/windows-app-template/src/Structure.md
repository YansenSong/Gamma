# assets / windows-app-template / src 文件结构

| 文件或目录 | 作用 |
| --- | --- |
| `main.py` | 命令行及图形界面入口。 |
| `app_service.py` | 组织工作簿输入、重算、报告与审计输出。 |
| `input_validation.py` | 输入记录的格式与范围校验。 |
| `project_validation.py` | 项目配置和模板绑定校验。 |
| `review_preview.py` | 只替换模板标记的 DOCX 渲染及未评分预览。 |
| `field_review_ui.py` | 报告字段审阅界面。 |
| `ui_design_system/` | 可复用界面组件和样式。 |

`README.md` 说明本目录用途；`Structure.md` 为本文件。
