# assets / windows-app-template 文件结构

| 文件或目录 | 作用 |
| --- | --- |
| `application.spec` | PyInstaller 打包配置。 |
| `build.ps1` | Windows 打包入口，产出 dist 下的完整应用目录。 |
| `requirements.txt` | 生成应用的 Python 依赖。 |
| `config/` | 项目配置骨架。 |
| `scripts/` | Excel 原生重算脚本。 |
| `src/` | 应用逻辑与界面代码。 |
| `tests/` | 应用契约测试骨架。 |

`README.md` 说明本目录用途；`Structure.md` 为本文件。
