# 第六章评分规程细则

> 独立整理版｜依据《智能行车指数测试与评价规程（2026版）》

> **整理范围：** 本文件以原规程第6章“评价方法”（原规程第16-24页）为主体，并结合第3-5章、附录A/B中的测试前提、数据口径，以及规范性附录C“真实交通适应性测试评价细则”（原规程第55-65页）进行独立整理。未改变原评分逻辑；为提高可读性，对表格、公式和条款顺序作了结构化重排。若本整理版与正式原规程存在差异，以正式原规程为准。

**常用符号：**SV=主车（Subject Vehicle）；RV=参考车辆（Reference Vehicle）；THW=车头时距（Time Headway）；AEB=自动紧急制动。

# 1 评分总框架

| **一级维度**   | **二级项目**       | **满分** |
|----------------|--------------------|----------|
| 连续场景通过性 | 具体试验场景得分   | 36       |
| 连续场景通过性 | 通行性得分         | 14       |
| 真实交通适应性 | 交通适应性场景得分 | 36       |
| 真实交通适应性 | 智能拟人化得分     | 8        |
| 真实交通适应性 | 行驶舒适性得分     | 6        |

**智能行车指数总分 = 连续场景通过性得分 + 真实交通适应性得分**

- 总分满分100分；连续场景通过性满分50分；真实交通适应性满分50分。

- 两个50分模块均各自设置罚分项，单个模块最终总罚分最多不超过10分。

# 2 评分前提与数据口径（结合其他章节）

## 2.1 测试次数与评分对象

- 连续场景通过性：封闭场地包含路线1（高速/城快连续场景）和路线2（城区连续场景），在试验有效前提下，每条路线进行1次试验。

- 真实交通适应性：开放道路规定路线进行2次试验；主车激活领航组合驾驶辅助系统，对实际遇到的规定试验场景/工况进行测试。

- 开放道路某一具体试验工况若遇到多次：每次单独评分，取多次工况得分的平均值（精确到小数点后2位）作为该工况最终得分。

## 2.2 连续场景试验操作约束

- 无特殊说明不得更改设置；驾驶员不得操作加速/制动踏板，不得人工辅助转向。

- 为避免领航组合驾驶辅助系统退出，驾驶员应双手放置于方向盘上或适时施加一定扭矩。

- 附录A规定的有效性要求包括：高速/城快路线在起点9s内达到初始车速、城区路线在3.5s内达到初始车速，并激活稳定至少2s；规定车速误差±1km/h、距车道中心线不超过±0.1m；静止目标物位置误差不超过±0.2m，运动目标物速度误差不超过±1km/h。

## 2.3 开放道路数据与参考车辆口径

- 速度采用GPS原始速度数据，单位km/h。

- 纵向/横向加速度采用12阶巴特沃斯滤波器，截止频率1.6Hz；该口径直接影响行驶舒适性扣分统计。

- 智能拟人化测试中，主车SV与参考车辆RV在相同测试路段起点、相同时间出发并沿相同路线行驶；整条路线被4个休息补能点划分为5个测试路段。

- 参考车辆RV由IVISTA官方认证测试专家驾驶；有效性要求包括测试专家全程遵守交通规则，以及同一次测试SV与RV路线相同。

# 3 连续场景通过性评分细则（50分）

**计算式：**连续场景通过性得分 = 具体试验场景得分 + 通行性得分 - 罚分。

## 3.1 具体试验场景得分（36分）

| **路线**         | **具体试验场景**             | **单场满分** |
|------------------|------------------------------|--------------|
| 路线1：高速/城快 | 隧道内遇交通事故             | 4.5          |
| 路线1：高速/城快 | 施工区域改道                 | 4.5          |
| 路线1：高速/城快 | 弯道遇抛锚车辆（车尾有行人） | 4.5          |
| 路线1：高速/城快 | 乘用车目标车切入             | 4.5          |
| 路线2：城区      | 隧道施工区域通行             | 4.5          |
| 路线2：城区      | 路口左转，多目标横穿         | 4.5          |
| 路线2：城区      | 直道遇倒地踏板式两轮摩托车   | 4.5          |
| 路线2：城区      | 立交桥遇抛锚车辆             | 4.5          |

**计算式：**S_ts = Σ(i=1…8) \[4.5 × R_ts,i\]，其中R_ts,i为第i个场景的得分率。

| **情形**                                                        | **无报警提示** | **有报警提示** | **单场折算说明** |
|-----------------------------------------------------------------|----------------|----------------|------------------|
| \(1\) 主车自主通过测试场景                                      | 100%           | 90%            | 4.50分 / 4.05分  |
| \(2\) 主车制动刹停；驾驶员拨打转向灯；车辆自主通过              | 90%            | 80%            | 4.05分 / 3.60分  |
| (3)-① AEB制动避撞后，由驾驶员控制车辆通过                       | 60%            | 70%            | 2.70分 / 3.15分  |
| (3)-② 主车制动刹停；拨打转向灯15s内未继续行驶；由驾驶员控制通过 | 70%            | 60%            | 3.15分 / 2.70分  |
| \(4\) 发生碰撞，碰撞前发出报警提示                              | —              | 15%            | 0.675分          |
| \(5\) 发生碰撞，碰撞前未发出报警提示                            | 0%             | —              | 0分              |

> **表9/表10关系：** 原规程表9以100%/90%/70%/15%/0%描述总体档位，表10进一步按“有/无报警提示”和第(3)档两种接管方式细化得分率。本整理以表10作为具体折算口径。触发AEB前是否报警、非AEB刹停前是否报警，分别会对(1)-(3)档得分率形成10个百分点的调整。

## 3.2 通行性得分（14分）

- 路线1和路线2通行性满分各7分。

- 记录主车SV从测试起点到测试终点的通行时间；原规程以20名经验驾驶员分别通行两条路线的平均时间为参考。

| **路线** | **主车通行时间**          | **通行性得分率** |
|----------|---------------------------|------------------|
| 路线1    | tSV1 ≤ 2分55秒            | 100%             |
| 路线1    | 2分55秒 \< tSV1 ≤ 3分25秒 | 80%              |
| 路线1    | 3分25秒 \< tSV1 ≤ 3分55秒 | 60%              |
| 路线1    | 3分55秒 \< tSV1 ≤ 4分25秒 | 40%              |
| 路线1    | tSV1 \> 4分25秒           | 20%              |
| 路线2    | tSV2 ≤ 5分44秒            | 100%             |
| 路线2    | 5分44秒 \< tSV2 ≤ 6分14秒 | 80%              |
| 路线2    | 6分14秒 \< tSV2 ≤ 6分44秒 | 60%              |
| 路线2    | 6分44秒 \< tSV2 ≤ 7分14秒 | 40%              |
| 路线2    | tSV2 \> 7分14秒           | 20%              |

**通行性得分：**S_dt = 7 × R_t1 + 7 × R_t2。

- 若路线1任一具体试验场景发生碰撞，则R_t1=0；若路线2任一具体试验场景发生碰撞，则R_t2=0。

## 3.3 连续场景罚分项（最多扣10分）

| **类别** | **罚分项**                                   | **每次扣分** |
|----------|----------------------------------------------|--------------|
| 交规符合 | 变道不打转向灯（紧急场景除外）               | 0.5          |
| 交规符合 | 压实线                                       | 0.5          |
| 决策规划 | 驶入错误的路线                               | 0.5          |
| 决策规划 | 驶入错误的车道                               | 0.5          |
| 行驶流畅 | 非场景路段内，驾驶员意料之外的制动           | 0.5          |
| 行驶流畅 | 车辆通过测试场景时，纵向加速度绝对值 ≥ 4m/s² | 0.5          |

- 每项罚分项最多扣3分；整个连续场景通过性模块总罚分最多10分。

- 实线变道例外：除响应适用道路设施/指示外，系统不得自动在实线处变道。不可抗力导致必须实线变道时，系统应提示测试人员接管，且除文字外至少含声学和光学警告；测试人员确认安全后控制变道，此类情况不罚分。

## 4.3 18项开放道路场景的具体判定细则（规范性附录C整理）

### 4.3.1 高速公路：拥堵走停

**第1档（100%）：**主车在L2激活状态下自动跟随本车道前车走停并完成规定拥堵路段通行，过程中未发出降级告警或报警提示。

**第2档（90%）：**主车在L2或L1激活状态下完成上述驾驶任务，过程中发出降级告警或报警提示。

**第3档（70%-X）：**主车仅完成部分任务，无法全程自动跟随前车走停，由驾驶员控制车辆通过拥堵走停路段。

**第4档（30%-X）：**主车全程无法自动跟随本车道前车走停，由驾驶员控制车辆通过该路段。

**注：**本条注明：功能降级仅指由L2降级为L1或L0，不包括L2内部功能切换、提醒驾驶员专注驾驶等提示。

### 4.3.2 高速公路：隧道通行

**第1档（100%）：**主车驶入隧道、通过隧道并驶出，系统持续进行横向和纵向控制，过程中未发出降级告警或报警提示。

**第2档（90%）：**完成同样隧道通行任务，过程中发出降级告警或报警提示。

**第3档（70%-X）：**可自动完成“驶入隧道、隧道通行、驶出隧道”中的部分驾驶任务，由驾驶员控制车辆通过隧道路段。

**第4档（30%-X）：**无法自动完成上述三个阶段的所有驾驶任务，由驾驶员控制车辆通过隧道路段。

### 4.3.3 高速公路：高速汇出匝道

**第1档（100%）：**识别本车道及相邻车道环境车辆，从高速主路完全变道至匝道；开始变道或系统提示确认变道时车轮未压实线/导流线，主车前部与匝道汇出口THW≥5s；无降级告警或报警提示。

**第2档（90%）：**完成同样任务并满足“未压实线/导流线、THW≥5s”，但过程中发出降级告警或报警提示。

**第3档（70%-X）：**可自动完成“驶离主路、向匝道汇入、进入匝道”中的部分任务，由驾驶员控制车辆完成高速汇出。

**第4档（30%-X）：**无法自动完成上述所有阶段，由驾驶员控制车辆从高速汇出至匝道。

### 4.3.4 高速公路：匝道内路线选择

**第1档（100%）：**根据导航信息驶入正确路径；开始变道或提示确认变道时，主车前部与导流区起始点THW≥5s；无降级告警或报警提示。

**第2档（90%）：**完成同样任务并满足THW≥5s，但过程中发出降级告警或报警提示。

**第3档（70%-X）：**可自动完成“向目标路径靠拢、在匝道分岔点沿目标路径行驶、驶入目标路径”中的部分任务，由驾驶员控制驶入正确匝道。

**第4档（30%-X）：**无法自动完成上述所有任务，由驾驶员控制驶入导航指示的正确匝道。

### 4.3.5 高速公路：匝道内急弯通行

**第1档（100%）：**可根据导航信息自动完成匝道内急弯通行，过程中未发出降级告警或报警提示。

**第2档（90%）：**完成匝道内急弯通行，过程中发出降级告警或报警提示。

**第3档（70%-X）：**急弯路段无法全程自动完成驾驶任务，由驾驶员控制车辆完成急弯通行。

**第4档（30%-X）：**急弯路段全程无法自动完成驾驶任务，由驾驶员控制主车正常通行。

### 4.3.6 高速公路：匝道汇入高速

**第1档（100%）：**识别本车道及相邻车道环境车辆，从匝道完全汇入高速主路；开始变道或提示确认变道时车轮未压实线/导流线，主车前部与加速车道尽头THW≥5s；无降级告警或报警提示。

**第2档（90%）：**完成同样任务并满足“未压实线/导流线、THW≥5s”，但过程中发出降级告警或报警提示。

**第3档（70%-X）：**可自动完成“驶离匝道、向主路汇入、进入主路”中的部分任务，由驾驶员控制主车汇入高速主路。

**第4档（30%-X）：**无法自动完成上述所有任务，由驾驶员控制主车汇入高速主路。

### 4.3.7 城市快速路：匝道出入口通行

**第1档（100%）：**识别本车道及相邻车道环境车辆，能够从城市地面道路驶入城市快速路匝道入口，或从城市快速路匝道出口驶出至城市地面道路；无降级告警或报警提示。

**第2档（90%）：**完成同样任务，过程中发出降级告警或报警提示。

**第3档（70%-X）：**能够自动完成驶入/驶出匝道对应阶段中的部分任务，由驾驶员控制完成匝道出入口通行。

**第4档（30%-X）：**无法自动完成驶入/驶出匝道对应阶段的所有驾驶任务，由驾驶员控制完成匝道出入口通行。

### 4.3.8 城区道路：拥堵走停

**第1档（100%）：**自动跟随本车道前车走停并完成规定拥堵路段通行，过程中未发出降级告警或报警提示。

**第2档（90%）：**完成同样任务，过程中发出降级告警或报警提示。

**第3档（70%-X）：**无法全程自动跟随前车走停，由驾驶员控制车辆通过拥堵走停路段。

**第4档（30%-X）：**全程无法自动跟随本车道前车走停，由驾驶员控制车辆通过该路段。

### 4.3.9 城区道路：急弯通行

**第1档（100%）：**根据导航信息完成急弯通行；过程中未发出降级告警或报警提示，且任一行驶轮未穿越车道线。

**第2档（90%）：**完成急弯通行；过程中发出降级告警或报警提示，且任一行驶轮未穿越车道线。

**第3档（70%-X）：**可根据导航完成部分急弯通行，但无法全程自动完成，由驾驶员控制车辆通过急弯路段。

**第4档（30%-X）：**全程无法自动完成驾驶任务，由驾驶员控制车辆完成急弯通行。

### 4.3.10 城区道路：主路辅路切换

**第1档（100%）：**识别本车道及相邻车道环境车辆，能够从城区道路主路驶入辅路或由辅路驶入主路；无降级告警或报警提示。

**第2档（90%）：**完成同样任务，过程中发出降级告警或报警提示。

**第3档（70%-X）：**可自动完成主路→辅路或辅路→主路三个阶段中的部分任务，由驾驶员控制完成切换。

**第4档（30%-X）：**无法自动完成上述切换阶段的所有驾驶任务，由驾驶员控制完成主辅路切换。

### 4.3.11 城区道路：车道选择

**第1档（100%）：**识别本车道及相邻车道环境车辆，根据导航指示选择对应车道行驶；无降级告警或报警提示。

**第2档（90%）：**完成同样任务，过程中发出降级告警或报警提示。

**第3档（70%-X）：**可自动完成对应车道选择中的部分任务（向目标路径靠拢、沿目标路径行驶、驶入目标路径），由驾驶员控制选择正确车道。

**第4档（30%-X）：**无法自动完成车道选择的所有任务，全程由驾驶员控制主车选择正确车道。

### 4.3.12 路口通行：主车进入路口前

**第1档（100%）：**识别本车道及相邻车道环境车辆，在行驶至路口车道实线之前变道至导航指示对应车道；无降级告警或报警提示。

**第2档（90%）：**完成同样任务，过程中发出降级告警或报警提示。

**第3档（70%-X）：**可自动完成“实线前变道、完成变道驶入对应车道”中的部分任务，由驾驶员控制完成进入路口前驾驶任务。

**第4档（30%-X）：**无法自动完成上述所有任务，由驾驶员控制驶入导航指示的对应车道。

### 4.3.13 路口通行：主车路口停止时

**第1档（100%）：**识别环境车辆，准确识别通行方向红灯并自动减速停止；无降级告警或报警提示。

**第2档（90%）：**完成同样任务，过程中发出降级告警或报警提示。

**第3档（70%-X）：**可完成“识别通行方向红灯（若无前方干扰车辆）、自动减速停止”中的部分任务，由驾驶员控制车辆停止于停止线处。

**第4档（30%-X）：**无法自动完成上述所有任务，由驾驶员控制车辆停止于停止线处。

**注：**若主车静止后车身外沿超出停止线，根据驾驶任务完成情况获得第3档或第4档得分。

### 4.3.14 路口通行：主车路口通行时

**第1档（100%）：**L2完成路口通行且无降级告警/报警。覆盖：①直行/左转/右转（无右转专用道、无待行区）：正确识别绿灯并及时启动；无右转专用灯时按交通规则安全右转。②右转有专用道：无灯时按规则安全通过，有灯时正确识别绿灯并及时启动。③直行/左转有待行区：正确识别待行区并依法驶入，识别绿灯并及时启动。

**第2档（90%）：**以L2或L1完成上述驾驶任务，过程中发出降级告警或报警提示。

**第3档（70%-X）：**可自动完成识别并响应交通信号灯（若无前方干扰车辆）中的部分任务，或可自动识别待行区并依法驶入的部分任务；由驾驶员控制驶入待行区或通过路口。

**第4档（30%-X）：**无法自动完成识别并响应交通信号灯的所有任务，或无法自动完成识别待行区并依法驶入的所有任务；由驾驶员控制驶入待行区或通过路口。

**注：**主车位于头车且L2激活：正确识别绿灯并在3s内起步，可获第1档或第2档；超过3s后启动，获第4档。

**注：**主车非头车且L2激活：前车启动后3s内跟随启动，可获第1档或第2档；超过3s后跟随启动，获第4档。

### 4.3.15 环岛通行：主车驶入环岛

**第1档（100%）：**识别本车道及相邻车道环境车辆，准确按交通信号灯指示（若有）驶入环岛；无降级告警或报警提示。

**第2档（90%）：**完成同样任务，过程中发出降级告警或报警提示。

**第3档（70%-X）：**可自动完成“识别响应交通信号灯（若有）、驶入环岛入口”中的部分任务，由驾驶员控制车辆驶入环岛。

**第4档（30%-X）：**无法自动完成上述所有任务，由驾驶员控制车辆驶入环岛。

### 4.3.16 环岛通行：主车环岛内行驶

**第1档（100%）：**识别本车道及相邻车道环境车辆，并根据交通规则在环岛内行驶；无降级告警或报警提示。

**第2档（90%）：**完成同样任务，过程中发出降级告警或报警提示。

**第3档（70%-X）：**可自动完成“识别响应交通信号灯（若有）、环岛车道内行驶、环岛内换道行驶”中的部分任务，由驾驶员控制主车在环岛内行驶。

**第4档（30%-X）：**无法自动完成上述所有任务，由驾驶员控制主车在环岛内行驶。

### 4.3.17 环岛通行：主车驶出环岛

**第1档（100%）：**识别本车道及相邻车道环境车辆，按交通信号灯（若有）正确行驶，并根据导航指示选择对应环岛出口驶出；无降级告警或报警提示。

**第2档（90%）：**完成同样任务，过程中发出降级告警或报警提示。

**第3档（70%-X）：**可自动完成“正确识别响应交通信号灯（若有）、从正确出口驶出环岛”中的部分任务，由驾驶员控制主车驶出环岛。

**第4档（30%-X）：**无法自动完成上述所有任务，由驾驶员控制主车驶出环岛。

### 4.3.18 城区道路：调头通行

**第1档（100%）：**识别环境车辆，按交通信号灯（若有）及交通规则执行调头任务（进入调头车道、调头过程、驶入目标车道），并避让有碰撞风险的目标物/目标车；无降级告警或报警提示。

**第2档（90%）：**完成同样任务，过程中发出降级告警或报警提示。

**第3档（70%-X）：**可自动完成调头通行三个阶段中的部分任务，由驾驶员控制车辆安全完成调头。

**第4档（30%-X）：**无法自动完成调头通行三个阶段的所有驾驶任务，由驾驶员控制车辆安全完成调头。

**注：**调头过程中不得严重影响对向直行车辆正常通行；“严重影响”指导致3辆及以上对向车辆无法正常通行。

**注：**若严重影响对向直行车辆正常通行超过20s，测试人员应控制车辆行驶并继续测试，该场景得分参考第3档或第4档。

## 4.4 智能拟人化得分（8分）

- 两次开放道路测试分别记录SV与RV通行时间tSVn、tRVn（n=1、2）。

- 计算每次时间差绝对值：Δt_n = \|tSVn - tRVn\|；取两次Δt_n平均值得到平均时间差；两次RV通行时间取平均。

- 通行时间偏差：σ = 平均时间差 / RV平均通行时间。

| **通行时间偏差σ** | **智能拟人化得分率R_ip** | **折算得分S_ip** |
|-------------------|--------------------------|------------------|
| σ ≤ 5%            | 100%                     | 8.0              |
| 5% \< σ ≤ 10%     | 80%                      | 6.4              |
| 10% \< σ ≤ 15%    | 40%                      | 3.2              |
| σ \> 15%          | 0                        | 0                |

**计算式：**S_ip = 8 × R_ip。

## 4.5 行驶舒适性得分（6分）

- 纵向加速度满分3分，横向加速度满分3分；仅评估正常行驶过程，不包括为保证安全的制动、停车、起步等（横向加速度不包括为保证安全的制动等）。

| **指标/场景**              | **第一档（每次扣0.2分）**  | **第二档（每次扣0.5分）** | **单项最高扣分** |
|----------------------------|----------------------------|---------------------------|------------------|
| 纵向加速度（所有选定路段） | 2.5m/s² ≤ \|a_x\| \< 4m/s² | \|a_x\| ≥ 4m/s²           | 3分              |
| 横向加速度-直行            | 1m/s² ≤ \|a_y\| \< 3m/s²   | \|a_y\| ≥ 3m/s²           | 3分              |
| 横向加速度-路口转弯        | 3m/s² ≤ \|a_y\| \< 5m/s²   | \|a_y\| ≥ 5m/s²           | 3分              |

| **场景** | **选定路段**                            |
|----------|-----------------------------------------|
| 直行     | 重庆市盘溪路                            |
| 直行     | 渝蓉高速：缙云山隧道出口-云雾山隧道入口 |
| 直行     | 成宜高速：富加北枢纽-清风枢纽           |
| 直行     | 成都市新华大道双林路                    |
| 路口转弯 | 重庆市渝中区渝州路与虎歇路路口          |
| 路口转弯 | 重庆市两江新区福康路与新南路路口        |
| 路口转弯 | 成都市湔江路与九寨沟路路口              |

**计算式：**S_dc = (3 - 0.2×n1 - 0.5×n2) + (3 - 0.2×n3 - 0.5×n4)。其中n1/n2为纵向加速度达到第一/第二档阈值的累计次数，n3/n4为横向加速度达到第一/第二档阈值的累计次数。

# 5 综合等级评价

| **等级**    | **得分率区间**      |
|-------------|---------------------|
| 优秀+（G+） | 得分率 ≥ 90%        |
| 优秀（G）   | 90% \> 得分率 ≥ 80% |
| 良好（A）   | 80% \> 得分率 ≥ 65% |
| 一般（M）   | 65% \> 得分率 ≥ 50% |
| 较差（P）   | 得分率 \< 50%       |

- 得分率 = 试验得分 ÷ 总分，并四舍五入保留1位小数。

- 原规程规定：当“智能安全复杂场景安全得分率”\<85%时，智能行车评价等级不得高于A。

> **重要原文歧义：** “智能安全复杂场景安全得分率”在本上传规程中仅出现在6.4综合等级评价处，文件内未给出该指标的单独计算式或组成定义。因此本整理版保留原条款，但不自行推定其计算方法。

# 6 一页式评分计算顺序

1. 先确认试验是否有效、测试次数是否满足要求，数据处理口径是否一致。

2. 连续场景：逐一判定8个具体场景得分率，折算36分；按两条路线通行时间折算14分；再扣连续场景罚分（最多10分）。

3. 真实交通：逐一判定18个开放道路工况得分率，折算36分；计算智能拟人化8分；按加速度阈值统计行驶舒适性6分；再扣开放道路罚分（最多10分）。

4. 两个模块相加得到100分制总得分。

5. 总得分除以100得到得分率，四舍五入保留1位小数，按G+/G/A/M/P区间定级；同时检查“复杂场景安全得分率\<85%则最高A”的限制条款。
