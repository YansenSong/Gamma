# 技能目录结构

| 路径 | 作用 |
| --- | --- |
| `SKILL.md` | Codex 执行本技能时遵循的流程和约束。 |
| `README.md` | 中文使用说明、整体流程与交付文件位置。 |
| `Structure.md` | 本目录索引。 |
| `requirements.txt` | 技能分析与验证脚本的 Python 依赖。 |
| `.gitignore` | 排除缓存等不应随技能交付的文件。 |
| `references/` | 规则编写、Excel 映射、报告映射和验收说明。 |
| `scripts/` | 三份材料的检查、项目初始化、公式写回和验证工具。 |
| `assets/` | 生成 Windows 应用时复制的基础模板。 |
| `tests/` | 技能工具及生成流程的回归测试。 |
| `vendor/` | 随技能一起交付的只读检查模块。 |

各子目录的文件说明见该目录的 `Structure.md`。运行时环境和生成项目均位于技能目录之外。
